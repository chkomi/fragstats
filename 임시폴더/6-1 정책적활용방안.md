# 6장. 정책적 활용방안

## 6.1. FRAGSTATS 경관지수 연계 농업진흥지역 설정기준안

### 가. 현행 지정기준의 한계와 개선 필요성

현행 농업진흥지역 지정기준은 단순 면적 기준(평야지 10ha, 중간지 7ha, 산간지 3ha)에 의존하여 다음과 같은 구조적 한계를 지닌다. 첫째, 논농사 위주의 집단화 기준으로 밭농사 지역이 체계적으로 누락된다(화순군 2등급 농지 보전 누락률 76.02%). 둘째, 농지의 공간 구조적 특성(형상, 연결성, 핵심부 비율)이 평가에서 제외된다. 셋째, 토양 조건, 기반시설 접근성, 토지이용 현황 등 다차원적 농지 가치가 반영되지 않는다.

본 연구에서는 이러한 한계를 극복하기 위해 경관생태학적 지표와 다차원 평가를 통합한 신규 설정기준을 제안한다. 새로운 기준은 '양적 보전'에서 '질적 관리'로의 정책 패러다임 전환을 구현하는 핵심 도구로 기능할 것이다.

### 나. FRAGSTATS 경관지수 기반 신규 설정기준안

#### 1) 농지 잠재력 지수(API) 기반 다차원 평가체계

본 연구에서 개발한 농지 잠재력 지수(API)는 4개 레이어의 가중합으로 농지 가치를 정량화한다.

**API 산출 체계**

```
API(x,y) = W_pibok × V_pibok + W_infra × V_infra + W_toyang × V_toyang + W_nongeup × V_nongeup
```

| 레이어 | 평가 항목 | 적합(cls_1) 기준 | 부적합(cls_9) 기준 |
|--------|-----------|------------------|---------------------|
| 피복(pibok) | 토지이용 현황 | 논, 밭 등 농업적 이용 | 시가화, 나지, 수역 등 |
| 기반시설(infra) | 농로·수리시설 접근성 | 500m 이내 | 500m 초과 |
| 토양(toyang) | 토양 적성 | 농업적성등급 1~2등급 | 3등급 이하 |
| 농업(nongeup) | 논 적성 | 논 적성등급 1~2등급 | 3등급 이하 |

*nongeup 레이어는 농촌진흥청 정밀토양도의 논 적성등급을 활용하며, 해당 토지가 논농사에 얼마나 적합한지를 평가한다.

**계층적 엔트로피 방법을 통한 가중치 산출**

각 레이어의 가중치는 농업진흥지역(cls_1)과 비농업진흥지역(cls_9)의 공간 구조적 차이를 30개 경관지수로 측정한 후, 2단계 엔트로피 분석(1차: 지표 수준, 2차: 레이어 수준)을 통해 객관적으로 산출한다.

가중치는 지역별 지형 특성에 따라 차별화되며, 본 연구의 나주시·화순군 분석 결과 다음과 같은 경향이 나타났다.

| 레이어 | 평야 지역(나주시) | 산지 지역(화순군) | 가중치 차이의 원인 |
|--------|------------------|------------------|--------------------|
| 피복(pibok) | 상대적 높음 | 상대적 낮음 | 평야는 토지이용 변화 민감, 산지는 지형 제약 우세 |
| 기반시설(infra) | 중간 수준 | 중간 수준 | 양 지역 모두 접근성 중요 |
| 토양(toyang) | 상대적 낮음 | 상대적 높음 | 평야는 토양 균질, 산지는 토양 이질성 큼 |
| 농업(nongeup) | 중간 수준 | 중간 수준 | 논 적성 평가 보편적 중요 |

*구체적 가중치 수치는 시·군별로 개별 산출하여 적용

**API 등급 분류**

| 등급 | API 점수 | 의미 | 지정 우선순위 |
|------|----------|------|---------------|
| 1등급 | 0.75 이상 | 최우량 농지 | 최우선 보전 |
| 2등급 | 0.50~0.75 | 우량 농지 | 우선 보전 |
| 3등급 | 0.25~0.50 | 보통 농지 | 조건부 보전 |
| 4등급 | 0.25 미만 | 저위 농지 | 보전 제외 |

#### 2) FRAGSTATS 경관지수 연계 공간 구조 기준

농지의 공간 구조적 효율성을 평가하기 위해 FRAGSTATS 경관지수를 지정 기준에 통합한다. 본 연구에서는 FRAGSTATS에서 제공하는 30개 클래스 수준 경관지수를 모두 산출하였으며, 계층적 엔트로피 분석을 통해 농업진흥지역과 비농업진흥지역을 효과적으로 변별하는 핵심 지표를 선정하였다.

**30개 경관지수 분석 및 핵심 지표 선정**

FRAGSTATS 클래스 수준에서 산출된 30개 지표는 면적/밀도/가장자리(CA, PLAND, NP, PD, LPI 등), 형상(SHAPE_MN, SHAPE_AM, FRAC_MN 등), 핵심부(TCA, CPLAND, CORE_MN, CORE_PCT 등), 연결성(COHESION, CONNECT, AI 등), 다양성(DIVISION, SPLIT 등) 범주로 분류된다.

계층적 엔트로피 분석 결과, 농업진흥지역과 비농업진흥지역의 공간 구조적 차이를 가장 효과적으로 변별하는 핵심 지표는 다음과 같이 선정되었다.

**핵심 경관지수 및 기준값**

| 경관지수 | 약어 | 논농사 기준 | 밭농사 기준 | 평가 의미 | 선정 근거 |
|----------|------|-------------|-------------|-----------|-----------|
| 응집도 지수 | COHESION | ≥ 90 | ≥ 85 | 농지 간 공간적 연결성 | cls_1/cls_9 변별력 최상위 |
| 핵심부 비율 | CORE_PCT | ≥ 70% | ≥ 65% | 가장자리 영향 최소화 | 농업 경영 효율성과 높은 상관 |
| 평균 패치 면적 | AREA_MN | ≥ 2.0 ha | ≥ 1.0 ha | 경영 규모의 경제 | 집단화 규모 보완 지표 |
| 형상 지수 | SHAPE_MN | 제한 없음 | ≤ 2.0 | 필지 형태 정형성 | 밭농사 농기계 작업 효율성 |

기준값은 나주시·화순군 농업진흥지역의 경관지수 분포 분석 및 변별력 평가 결과를 바탕으로 설정하였다.

#### 3) 영농 형태별 차별화 기준

현행 획일적 기준의 한계를 극복하기 위해 논농사와 밭농사의 구조적 차이를 반영한 차별화 기준을 제안한다.

**논농사 지역 지정기준**

| 구분 | 제안 기준 | 근거 |
|------|-----------|------|
| 집단화 규모 | 평야지 10ha, 중간지 7ha, 산간지 3ha | 현행 기준 유지 |
| 공간 구조 | COHESION ≥ 90, CORE_PCT ≥ 70% | 경관지수 기준 추가 |
| API 요건 | 1등급 50% 이상 | 질적 수준 확보 |

**밭농사 지역 지정기준**

| 구분 | 제안 기준 | 논농사 대비 | 차별화 근거 |
|------|-----------|-------------|-------------|
| 집단화 규모 | 평야지 5ha, 중간지 3.5ha, 산간지 1.5ha | 50% 완화 | 밭농사 소규모 분산 특성 |
| 공간 구조 | COHESION ≥ 85, CORE_PCT ≥ 65%, SHAPE_MN ≤ 2.0 | 완화된 연결성, 형상 기준 추가 | 집단화 질 유지 |

밭농사 지역은 집단화 규모를 50% 완화하되, API 기준을 상향하고 형상 기준을 추가하여 질적 수준을 보완한다.

   - 현장 조사를 통한 실태 확인

## 6.2. 농업생산기반시설 투자 우선순위 결정 모델

### 가. 투자 우선순위 결정의 필요성

농업생산기반시설 투자는 한정된 예산(2022년 2.1조원) 내에서 최대 효과 창출을 목표로 한다. 그러나 현행 투자 결정 체계는 객관성 부족(지역 간 형평성·정치적 고려 우선), 다차원 평가 부재(단편적 지표 의존), 투자 효과 사전 예측 곤란 등의 한계를 지닌다.

본 연구에서는 API와 FRAGSTATS 경관지수를 활용하여 투자 효과를 사전 예측하고 객관적 우선순위를 결정하는 모델을 제안한다.

### 나. 투자 우선순위 결정 모델

#### 1) 모델 구조

투자 우선순위는 4개 차원의 종합 점수로 결정된다.

```
Priority_Score = α × Potential_Score + β × Improvement_Score + γ × Efficiency_Score + δ × Structure_Score
```

**차원별 평가 지표**

| 차원 | 평가 내용 | 점수 산출 방법 | 가중치 |
|------|-----------|----------------|--------|
| 농지 잠재력 (Potential) | 현재 API 등급 | 1등급 100점 ~ 4등급 25점 | α = 0.30 |
| 개선 잠재력 (Improvement) | 투자 후 API 향상 가능성 | 기반시설 부적합 → 적합 전환 시 최고점 | β = 0.30 |
| 투자 효율성 (Efficiency) | 단위 면적당 투자 효과 | 수혜 면적 100ha 이상 100점 ~ 20ha 미만 25점 | γ = 0.20 |
| 공간 구조 (Structure) | FRAGSTATS 경관지수 (30개 지표 중 선정) | 핵심 지표 종합 점수 | δ = 0.20 |

*공간 구조 점수는 30개 경관지수 중 변별력이 높은 COHESION, CORE_PCT, AREA_MN, SHAPE_MN 등을 종합하여 산출

기본 가중치는 균형형(α=β=0.30, γ=δ=0.20)을 제안하며, 투자 목적에 따라 조정 가능하다.

#### 2) 개선 잠재력 평가 (핵심 차별화 요소)

투자를 통한 API 향상 가능성을 정량적으로 예측한다. 특히 기반시설 레이어에서 부적합(cls_9) 판정을 받은 지역은 기반시설 투자를 통해 적합(cls_1)으로 전환되어 API가 향상된다.

| 현재 상태 | 투자 후 예상 API 변화 | 개선 잠재력 점수 |
|-----------|----------------------|------------------|
| 기반시설 부적합, 피복·토양·농업 모두 적합 | 4등급 → 1등급 (가중치만큼 향상) | 100점 |
| 기반시설 부적합, 2개 레이어 적합 | 3등급 → 2등급 | 75점 |
| 기반시설 부적합, 1개 레이어 적합 | 4등급 → 3등급 | 50점 |
| 기반시설 이미 적합 | 변화 없음 | 25점 |

이를 통해 "투자 전 잠재력은 낮으나 투자 후 크게 향상될 수 있는 지역"을 식별하여 투자 효율을 극대화한다.

### 다. 투자 유형별 우선순위 기준

#### 1) 농업용수 공급시설 (저수지, 양수장, 배수장)

수혜 면적이 넓으므로 투자 효율성(γ)과 개선 잠재력(β)을 중시한다.

| 우선순위 | 기준 | 점수 범위 |
|----------|------|-----------|
| 최우선 | 수혜 면적 100ha 이상, API 1~2등급 지역 | 85점 이상 |
| 우선 | 수혜 면적 50ha 이상, API 2등급 이상 지역 | 70~85점 |
| 일반 | 수혜 면적 20ha 이상, API 3등급 이상 지역 | 50~70점 |

**적용 예시: 나주시 C1 지역 2,360ha** - 용수 공급 미흡 지역을 우선 투자 대상으로 선정하면 API 향상 및 농업진흥지역 신규 지정 근거 마련

#### 2) 농로 (농업용 도로)

공간적 연결성 향상에 중점을 두어 공간 구조(δ)를 중시한다.

| 우선순위 | 기준 | 점수 범위 |
|----------|------|-----------|
| 최우선 | COHESION 향상 10% 이상 예상, API 1~2등급 지역 | 85점 이상 |
| 우선 | COHESION 향상 5% 이상 예상, API 2등급 이상 지역 | 70~85점 |

**적용 예시: 화순군 밭농사 지역** - 농로 연결로 COHESION 향상 시 완화된 집단화 기준 충족 → 신규 지정 가능

#### 3) 경지정리 사업

형상 개선 및 핵심부 비율 향상에 중점을 둔다.

| 우선순위 | 기준 | 점수 범위 |
|----------|------|-----------|
| 최우선 | CORE_PCT 20%p 이상 향상 예상, API 1~2등급 지역 | 85점 이상 |
| 우선 | CORE_PCT 10%p 이상 향상 예상, API 2등급 이상 지역 | 70~85점 |

### 라. 모델 적용 효과

투자 우선순위 결정 모델 적용을 통해 ① 투자 결정의 객관성 확보 (정량적 지표 기반), ② 투자 효과 사전 예측 가능 (개선 잠재력 평가), ③ 농업진흥지역 제도와의 선순환 구조 형성 (투자 → API 향상 → 신규 지정 → 투자 효과 지속)이 달성된다.

- **경관지수 산출**: FRAGSTATS를 통한 30개 클래스 수준 경관지수 산출 체계 구축
- **가중치 산출 체계**: 시·군별 계층적 엔트로피 가중치 개별 산출 (30개 경관지수 기반 2단계 분석) 및 주기적 갱신
- **시스템 구축**: API 산출, 경관지수 분석, 투자 우선순위 결정을 통합 지원하는 GIS 기반 의사결정지원시스템

#### 3) 사회적 고려사항

- **이해관계자 참여**: 재조정 계획 수립 단계부터 주민 설명회, 공청회를 통한 의견 수렴
- **점진적 적용**: 시범 적용 → 문제점 개선 → 순차 확대 적용
- **보상 및 지원**: 신규 지정 지역 토지 소유자 대상 세제 혜택, 농업 보조금 우선 지원

### 라. 결론

본 연구에서 제안한 FRAGSTATS 경관지수 연계 신규 설정기준과 투자 우선순위 결정 모델은 다음과 같은 차별화된 기여를 한다.

**방법론적 기여**
- 계층적 엔트로피 방법을 통한 객관적 가중치 산출 (레이어 가중치, 경관지수 선정)
- 4개 레이어 통합 농지 잠재력 지수(API) 개발 (피복, 기반시설, 토양, 논 적성)
- FRAGSTATS 30개 클래스 수준 경관지수 분석 및 핵심 지표 선정을 통한 공간 구조 정량화
- 투자 효과 사전 예측 모델 개발 (개선 잠재력 평가)

**정책적 기여**
- 논농사/밭농사 차별화 기준을 통한 밭농사 보전 누락 해소
- 농업진흥지역 지정과 기반시설 투자의 선순환 구조 형성
- 지역별 맞춤형 평가 (평야/산지 가중치 차별화)
- 양적 보전에서 질적 관리로의 정책 패러다임 전환 구현

본 연구의 접근 방법은 농업 분야를 넘어 증거 기반 국토 관리 정책의 선도 모델로 확산될 수 있을 것으로 기대된다.
