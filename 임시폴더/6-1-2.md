# 6장. 정책적 활용방안

## 6.1-2. 최종 분석결과 연계 정책 활용방안 (수정본)

### 가. 현행 지정기준의 한계와 신규 기준의 필요성

현행 농업진흥지역 지정기준은 1992년 도입된 이후 큰 변화 없이 단순 면적 기준(평야지 10ha 등)과 논농사 위주의 집단화 개념에 의존하고 있다. 이로 인해 다음과 같은 명백한 한계가 드러났다.

1.  **밭농사 지역의 체계적 누락**: 본 연구의 정합성 분석 결과, 특히 화순군에서 2등급 우량농지의 보전 누락률이 76.02%에 달하는 등, 현행 기준이 밭농사 지역의 공간적 특성을 제대로 반영하지 못함이 실증되었다.
2.  **공간 구조적 가치 미반영**: 동일 면적이라도 필지의 형태, 집적도, 연결성, 핵심부 면적 비율 등 기계화 영농 효율성과 직결되는 공간 구조적 가치를 전혀 평가하지 못한다.
3.  **지역별 특성 미고려**: 본 연구의 핵심 발견 사항인 **지역별 농지 가치 결정 요인의 차이**—화순(중산간)은 `nongeup`(논 적성) 등 자연적 조건이, 나주(평야)는 `pibok`(필지 복잡도)과 `infra`(기반시설) 등 인위적·관리적 조건이 중요하다는 점—를 전혀 반영하지 못하고 획일적인 기준을 적용한다.

따라서 본 연구는 이러한 한계를 극복하기 위해, **①다차원적 가치 평가**, **②공간 구조의 정량화**, **③지역별 특성 차별화**를 핵심 원칙으로 하는 새로운 농업진흥지역 설정 및 관리 방안을 제안한다. 이는 단순한 '양적 보전'에서 데이터 기반의 '질적 관리'로 정책 패러다임을 전환하는 핵심 도구가 될 것이다.

### 나. 농지 잠재력 지수(API) 기반 신규 지정 및 해제 기준

#### 1) 농지 잠재력 지수(API)의 개념과 구조

본 연구에서 개발한 **농지 잠재력 지수(API)**는 4개 핵심 레이어(pibok, infra, toyang3, nongeup)의 가치를 객관적 가중치로 종합하여, 모든 농지(픽셀)의 잠재력을 0과 1 사이의 단일 점수로 정량화한 지표이다.

**API 산출 공식:**
`API(x,y) = (W_pibok × V_pibok) + (W_infra × V_infra) + (W_toyang3 × V_toyang3) + (W_nongeup × V_nongeup)`

-   `W_layer`: 각 레이어의 **지역별 차등 가중치** (계층적 엔트로피 분석으로 산출)
-   `V_layer`: 해당 픽셀이 각 레이어에서 '적합(cls_1)'이면 1, '부적합(cls_9)'이면 0

#### 2) 핵심: 계층적 엔트로피 분석 기반의 '지역별 차등 가중치'

API의 가장 큰 특징은 **지역별 차등 가중치**에 있다. 이 가중치는 각 레이어가 '적합 농지(cls_1)'와 '부적합 농지(cls_9)'의 공간 구조적 차이를 얼마나 잘 **변별**하는지를 정량화한 '변별력(Discriminability)'에 기반하여 산출된다.

**표 6-1. 최종 분석 기반 지역별 레이어 가중치 비교**

| 레이어 | 화순 가중치 (중산간) | 나주 가중치 (평야) | 지역별 가중치 차이의 정책적 함의 |
|:---|---:|---:|:---|
| **nongeup** (논 적성) | **41.53%** (1위) | 15.98% (3위) | **화순**은 자연적 조건이 농지 구조를 결정하므로, **현존 우량 논 농지 보전**이 최우선. |
| **pibok** (필지 복잡도) | 23.36% (2위) | **38.55%** (1위) | **나주**는 인위적 관리가 중요하므로, **경지정리, 집단화** 등 구조 개선 투자가 효과적. |
| **infra** (기반시설) | 17.10% (4위) | **38.16%** (2위) | **나주**는 **기반시설 확충**을 통한 가치 향상 잠재력이 높음. |
| **toyang3** (토양 적성) | 18.01% (3위) | 7.31% (4위) | **화순**은 토양 조건이 상대적으로 중요하나, **나주**에서는 변별력이 낮음. |

이처럼 지역별로 상이한 가중치를 적용함으로써, 각 지역의 지형적·인문적 특성에 맞는 맞춤형 농지 평가가 가능해진다.

#### 3) API 등급별 지정 및 해제 기준(안)

API 점수를 기반으로 농지를 4개 등급으로 분류하고, 이에 따른 지정·해제 기준을 제시한다.

**표 6-2. API 등급별 지정·해제 기준(안)**

| 등급 | API 점수 | 의미 | 지정·해제 방침 | 정합성 분석 연계 |
|:---:|:---|:---|:---|:---|
| **1등급** | 0.75 이상 | 최우량 농지 | **신규 지정 최우선 검토** | C1 지역 (긴급 보전 누락) |
| **2등급** | 0.50 ~ 0.75 | 우량 농지 | **신규 지정 중장기 검토** | C2 지역 (중장기 보전 누락) |
| **3등급** | 0.25 ~ 0.50 | 보통 농지 | 현상 유지 또는 조건부 해제 검토 | B 지역 중 일부 |
| **4등급** | 0.25 미만 | 저위 농지 | **해제 최우선 검토** (기반시설 제외) | B 지역 중 대부분 |

#### 4) 공간 구조 기준의 보완적 활용

API가 농지의 다차원적 가치를 평가한다면, FRAGSTATS 경관지수는 집단화의 '질'을 평가한다. API 등급 기준을 충족하더라도, 아래의 공간 구조 기준을 만족하지 못하면 지정을 재검토하거나, 반대로 기준을 만족하면 지정의 정당성을 강화하는 보완재로 활용한다.

-   **핵심 지표**: **CORE_MN**(평균 코어 면적), **AREA_MN**(평균 패치 면적), **GYRATE_MN**(평균 회전반경), **PARA_MN**(평균 둘레-면적 비) 등 그룹별 가중치가 높게 나타난 지표들을 활용.
-   **활용 방안**: API 2등급 지역 중에서도 CORE_MN, AREA_MN이 상위 20% 이내인 지역은 신규 지정 우선순위를 상향 조정.

### 다. 지역별 맞춤형 농업진흥지역 재조정 전략

본 연구의 정합성 분석 결과 드러난 지역별 문제 구조에 따라, 다음과 같은 차별화된 재조정 전략을 제안한다.

#### 1) 나주시: '조정형(Re-balancing)' 전략

-   **문제 진단**: 부적정 지정(B유형, 4,963ha, 진흥지역의 30.9%)이 보전 누락(C유형, 5,559ha)과 비슷한 규모로 존재.
-   **전략 목표**: 총량은 유지하되, '나쁜' 농지는 해제하고 '좋은' 농지는 신규 지정하여 **적재적소에 재배치**.
-   **실행 방안**:
    -   **해제**: B유형 4,963ha 중 API 4등급 지역을 우선 해제. (단, 저수지 등 기반시설 제외)
    -   **신규 지정**: C1유형 2,360ha(긴급) 및 C2유형 3,199ha(중장기)를 신규 지정.
-   **기대 효과**: 순 증감은 +596ha에 불과하나, 약 10,522ha 토지의 지정 상태가 재배치되어 제도의 정합성 대폭 향상. 불필요한 규제 완화와 우량농지 보전 강화 동시 달성.

#### 2) 화순군: '확대형(Expansion)' 전략

-   **문제 진단**: 부적정 지정(B유형, 1,048ha, 진흥지역의 16.5%)은 미미한 반면, **보전 누락(C유형, 6,702ha)이 심각**. 특히 우량농지의 **55.88%**가 제도권 밖에 방치.
-   **전략 목표**: 제한적인 우량농지 자원을 최대한 보전하기 위해 **신규 지정을 대폭 확대**.
-   **실행 방안**:
    -   **신규 지정**: C1유형 2,121ha(긴급)를 최우선 지정하고, C2유형 4,581ha(중장기)에 대한 단계적 지정 추진.
    -   **해제**: B유형 1,048ha의 해제는 후순위로 검토.
-   **기대 효과**: 순 증감 +5,654ha 이상. 우량농지 보전율을 현 44.12%에서 80% 이상으로 끌어올려, 산간 지역의 취약한 농업 생산 기반 안정화.

### 라. API 연계 농업생산기반시설 투자 우선순위 결정 모델

한정된 기반시설 투자 예산의 효율성을 극대화하기 위해, API와 연계한 객관적 투자 우선순위 결정 모델을 제안한다.

-   **핵심 개념**: '개선 잠재력' 평가. 투자를 통해 API 등급이 얼마나 상승할 수 있는지를 정량적으로 예측.
-   **평가 항목**: ①**현재 잠재력**(API 점수), ②**개선 잠재력**(투자 후 API 상승폭), ③**투자 효율성**(수혜 면적), ④**공간 구조**(COHESION, CORE_MN 등)를 종합 평가.
-   **우선 투자 대상**: 현재 API는 낮으나(2~3등급), 기반시설 미비가 주원인이어서 **투자 시 API 상승폭이 큰 지역**.
-   **정책 연계**:
    -   **나주시**: C1, C2 지역 중 기반시설이 부족한 곳에 우선 투자하여 API 등급을 상향시킨 후, 농업진흥지역으로 신규 지정하는 선순환 구조 창출.
    -   **화순군**: 밭농사 위주의 C1, C2 지역에 농로 연결 사업을 집중 투자하여 공간 구조(COHESION 등)를 개선하고, 완화된 밭농사 지정 기준을 충족시켜 신규 지정을 유도.

### 마. 정책 로드맵 및 결론

#### 1) 3단계 정책 로드맵

-   **1단계 (기반 구축, 1~2년)**: API 산출 시스템 전국 확대 및 법령 개정(밭농사 기준 신설 등). 시·군별 지역별 차등 가중치 산출.
-   **2단계 (긴급 재조정, 2~3년)**: 전국 C1(최우량 농지 누락) 지역 긴급 신규 지정 및 B유형 중 API 4등급 지역 우선 해제.
-   **3단계 (확대 및 완성, 3~5년 이상)**: C2(우량 농지 누락) 지역 단계적 지정 및 API 연계 기반시설 투자 본격화. 우량농지 보전율 80% 목표 달성.

#### 2) 결론: 증거 기반의 과학적 농정으로의 전환

본 연구가 제안하는 정책 활용방안은 과거의 획일적·정성적 기준에서 벗어나, **객관적 데이터(API)와 과학적 분석(계층적 엔트로피)**에 기반한 '증거 기반 정책(Evidence-Based Policy)'으로의 전환을 의미한다. 이는 농지 보전의 실효성을 높이는 동시에, 불필요한 규제를 완화하여 농민의 수용성을 제고하고, 지역별 특성에 맞는 맞춤형 정책을 통해 국토의 지속가능한 발전에 기여할 것이다. 본 방법론은 비단 농지뿐만 아니라, 향후 다양한 토지이용 관리 정책 수립에 적용될 수 있는 선도적 모델이 될 것으로 기대한다.
