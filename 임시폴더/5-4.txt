4) 영농불리지역과의 정합성 평가: 독립적 검증을 통한 모델 타당성 확인

 본 연구에서 정립한 농지 잠재력 지수(API)의 타당성을 검증하기 위해, 농업진흥지역과는 독립적으로 지정·운영되는 '영농불리지역'과의 공간적 중첩 정도를 분석하였다. 영농불리지역은 「농어업인 삶의 질 향상 및 농어촌지역 개발촉진에 관한 특별법」 제3조 및 동법 시행령 제2조에 근거하여, 경지율이 22% 이하이거나 경지 경사도가 14% 이상인 지역으로서 농업생산 여건이 불리한 농촌 지역을 의미한다. 이 제도는 유럽연합(EU)의 Less Favoured Areas(LFA) 정책을 벤치마킹한 것으로, 농업생산에 구조적으로 불리한 지역에 대한 소득 보전 및 지역사회 유지를 목적으로 한다.

 영농불리지역은 본 연구의 API 산정에 직접적으로 사용되지 않은 독립적인 지정 기준이다. API는 토지이용피복도(Pibok), 농업생산기반시설(Infra), 토양도(Toyang3), 농업진흥지역(Nongeup)이라는 4개 레이어의 공간 구조적 특성을 종합하여 산출되었으며, 경지율이나 경사도와 같은 영농불리지역의 지정 기준은 직접 반영되지 않았다. 따라서 API 고득점 지역과 영농불리지역 간의 공간적 배타성을 분석하는 것은, 본 모델이 농업적으로 불리한 환경을 적절히 식별하고 배제하는지를 검증하는 독립적인 교차검증(cross-validation) 수단이 된다.

 분석 결과, API 0.5 이상 고득점 지역 중 영농불리지역이 차지하는 비율은 매우 낮게 나타났다. 나주시의 경우, API 0.5 이상 지역은 총 16,667.1 ha이며, 이 중 영농불리지역은 16.66 ha로 전체의 0.10%에 불과하였다. 화순군의 경우, API 0.5 이상 지역 11,995 ha 중 영농불리지역은 124.37 ha로 1.04%를 차지하였다. 두 지역 모두 API 고득점 지역의 99% 이상이 영농불리지역 외부에 위치하고 있어, 본 연구의 모델이 농업생산에 불리한 지역을 효과적으로 배제하고 있음이 확인되었다.

 이러한 결과는 다음과 같은 의미를 가진다. 첫째, API 모델의 구조적 타당성이 확보되었다. 본 연구의 API는 경사도나 경지율을 직접적인 평가 변수로 사용하지 않았음에도 불구하고, 이러한 조건이 불리한 영농불리지역을 자동적으로 낮은 점수로 평가하고 있다. 이는 API를 구성하는 4개 레이어(토지이용, 기반시설, 토양, 농업진흥지역)와 30개 경관지수가 농업 생산성에 영향을 미치는 복합적 요인들을 간접적으로 포착하고 있음을 의미한다. 경사도가 높은 지역은 일반적으로 토지이용피복도에서 농지 비율이 낮고, 농업생산기반시설 투자가 부족하며, 토양 조건이 불리하고, 농업진흥지역으로 지정되지 않았을 가능성이 높다. 따라서 이러한 조건들의 공간 구조적 특성을 종합한 API는 영농불리 요인을 간접적으로 반영하게 된다.

 둘째, 나주(0.10%)와 화순(1.04%) 간의 차이는 두 지역의 지형적 특성 차이를 반영한다. 화순군은 산지 비율이 높고 지형 기복이 큰 내륙 지역으로, 상대적으로 영농불리지역이 넓게 분포하며, 일부 API 고득점 지역이 영농불리지역 경계부에 인접할 가능성이 있다. 반면, 나주시는 영산강 유역의 평야 지대로 경사도가 낮고 경지율이 높아, 영농불리지역 자체가 제한적으로 분포한다. 이러한 지역 간 차이에도 불구하고, 두 지역 모두 API 고득점 지역의 99% 이상이 영농불리지역과 중첩되지 않았다는 사실은, 본 모델이 지역적 특성에 관계없이 일관되게 농업 적합 지역을 식별하고 있음을 보여준다.

 셋째, 정책적 관점에서 본 결과는 API를 활용한 농업진흥지역 재조정의 합리성을 뒷받침한다. 영농불리지역은 이미 정책적으로 농업생산 여건이 불리하다고 인정받은 지역이며, 이러한 지역은 농업진흥지역 지정 대상에서 제외되는 것이 타당하다. 본 연구의 API가 영농불리지역을 거의 포함하지 않는 고득점 지역을 식별했다는 것은, API 기반 평가가 기존의 다양한 농업 정책 기준들과 논리적으로 정합적임을 의미한다. 만약 API 고득점 지역이 영농불리지역과 높은 비율로 중첩되었다면, 이는 모델의 구조적 결함을 시사하는 것이지만, 본 분석 결과는 그 반대를 입증한다.

 넷째, 극소수 존재하는 중첩 지역(나주 16.66 ha, 화순 124.37 ha)은 API 모델의 현실적 적용 시 추가 검토가 필요한 경계 사례(edge case)로 해석할 수 있다. 이러한 지역은 경사도나 경지율과 같은 물리적 조건은 불리하지만, 토양 조건이나 기반시설 접근성 등 다른 요인에서 상대적으로 유리하여 API가 높게 산출된 것으로 추정된다. 정책 적용 단계에서는 이러한 소수의 중첩 지역에 대해 현장 조사 및 추가 평가를 통해 최종 지정 여부를 결정하는 것이 바람직하다. 다만, 전체 API 고득점 지역 대비 0.1~1% 수준에 불과한 이러한 예외 사례의 존재가 모델 전체의 타당성을 훼손하는 것은 아니다.

 한편, 본 분석은 API 모델의 한계를 동시에 시사한다. 영농불리지역과의 배타성이 높다는 것은 긍정적이지만, 이것이 API가 영농불리 요인을 '직접적으로' 측정한다는 의미는 아니다. API는 어디까지나 토지이용, 기반시설, 토양, 법적 지정이라는 4개 차원의 공간 구조적 특성을 종합한 것이며, 경사도와 같은 지형적 조건은 이들 레이어를 통해 '간접적으로' 반영될 뿐이다. 따라서 향후 연구에서는 경사도, 경지율, 접근성 등의 직접적인 물리적 조건을 추가 레이어로 포함하거나, 또는 API 산출 후 이러한 조건을 필터링 기준으로 적용하는 2단계 평가 체계를 구축하는 것도 검토할 수 있다.

 또한, 영농불리지역 제도 자체의 한계도 고려해야 한다. 영농불리지역은 경지율 22% 이하 또는 경사도 14% 이상이라는 단순한 임계값 기준으로 지정되며, 본 연구의 API와 같은 다차원적·정량적 평가 체계를 갖추지 못하고 있다. 따라서 영농불리지역과의 낮은 중첩률이 API의 우수성을 입증하는 것일 수도 있지만, 반대로 영농불리지역 지정 기준 자체가 불완전하여 일부 농업 부적합 지역을 누락하고 있을 가능성도 배제할 수 없다. 이는 향후 두 제도 간의 상호 보완적 발전 방향을 모색할 필요성을 제기한다.

 결론적으로, API 0.5 이상 고득점 지역 중 영농불리지역이 차지하는 비율이 나주 0.10%, 화순 1.04%로 매우 낮게 나타난 것은, 본 연구에서 정립한 농지 잠재력 평가 모델이 독립적인 검증 기준과 높은 정합성을 보이며, 농업생산에 불리한 지역을 효과적으로 배제하는 구조적 타당성을 갖추고 있음을 입증한다. 이는 API를 기반으로 한 농업진흥지역 재조정 정책의 과학적 근거를 강화하며, 다만 소수의 예외 사례에 대해서는 현장 검증 등 추가적인 정책적 검토가 필요함을 시사한다.
