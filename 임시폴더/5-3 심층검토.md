# 5.3. 정합성 분석 결과 심층 검토

## 가. 저수지의 농업진흥지역 지정 기준 검토

### 1) 문제 제기

본 연구의 정합성 분석 결과, 농업진흥지역 내에서 농지 잠재력 지수(API)가 낮게 나타난 부적정 지정 지역(유형 B)의 상당 부분이 저수지인 것으로 확인되었다. 나주시의 경우 저수지가 농업보호구역으로 지정되어 있어 법적 근거가 명확한 반면, 화순군의 경우 저수지가 농업진흥구역으로 지정되지 않은 경우도 상당수 존재하는 것으로 파악되었다.

이러한 지역 간 차이는 저수지의 농업진흥지역 지정이 의무인지 재량인지, 규모나 기능에 따른 기준이 있는지에 대한 검토 필요성을 제기한다. 본 절에서는 관련 법령을 면밀히 분석하여 저수지 지정의 법적 기준과 실무적 적용 방안을 검토한다.

### 2) 관련 법령 검토

#### (1) 농업진흥지역의 구분

「농지법」 제28조에 따르면, 농업진흥지역은 농업진흥구역과 농업보호구역으로 구분된다.

| 구분 | 정의 | 주요 대상 |
|------|------|-----------|
| 농업진흥구역 | 농업의 진흥을 도모하기 위하여 농지가 집단화되어 있고 농업 목적으로 이용할 필요가 있는 지역 | 경지정리된 농지, 집단화된 논·밭 |
| 농업보호구역 | 농업진흥구역의 용수원 확보, 수질 보전 등 농업 환경을 보호하기 위하여 필요한 지역 | 저수지, 양수장, 하천 유역 등 |

이러한 구분에 따르면, 저수지는 농업진흥구역이 아닌 **농업보호구역**의 지정 대상이다. 저수지는 농업 생산이 직접 이루어지는 토지가 아니라, 농업진흥구역에 용수를 공급하는 지원 시설이기 때문이다.

#### (2) 농업보호구역 지정 기준

「농지법」 시행령 제30조 및 농업진흥지역관리규정 제4조에 따른 농업보호구역 지정 기준을 검토하면 다음과 같다.

**농림지역·관리지역·자연환경보전지역의 농업보호구역 지정 대상:**

> "농업진흥구역의 용수원 확보와 수질보전을 위하여 농업진흥구역에 필요한 수원공(저수지 등)의 **직접유역** 안에 있는 모든 토지"

여기서 핵심 개념은 **"직접유역"**이다. 직접유역이란 저수지로 직접 유입되는 집수 구역을 의미하며, 이 구역 내의 토지가 농업보호구역 지정 대상이 된다.

**중요한 점은 저수지 자체(수면)가 농업보호구역 지정 대상인지에 대한 명시적 규정이 없다는 것이다.** 규정은 "직접유역 안에 있는 토지"를 대상으로 하고 있으며, 저수지 수면 자체를 포함하는지는 명확하지 않다.

#### (3) 저수지 규모별 기준 존재 여부

**결론: 저수지 규모별 지정 기준은 존재하지 않는다.**

농업진흥지역관리규정을 검토한 결과, 저수지의 규모(저수량, 수면적, 관개면적 등)에 따른 농업보호구역 지정 기준은 명시되어 있지 않다. 다만, 관련 규정에서 저수지와 관련된 거리 기준이 일부 존재한다.

**저수지 관련 거리 기준 (변경·해제 관련):**

농업진흥지역관리규정 제5조에 따르면, 다음의 경우 농업진흥구역을 농업보호구역으로 변경할 수 있다:

> "저수지의 계획홍수위선(計劃洪水位線)으로부터 상류 반경 500미터 이내의 지역으로서 「농어촌정비법」에 따른 농업생산기반 정비사업이 시행되지 않은 지역"

이 규정은 저수지 주변 지역의 구역 변경에 관한 것으로, 저수지 자체의 지정 의무와는 무관하다.

#### (4) 저수지 지정의 의무 여부

**결론: 저수지의 농업보호구역 지정은 의무가 아닌 재량이다.**

관련 법령을 종합 검토한 결과, 저수지를 농업보호구역으로 지정해야 한다는 의무 규정은 존재하지 않는다. 「농지법」 및 관련 규정은 농업보호구역의 지정 "대상"을 규정하고 있을 뿐, 특정 토지나 시설에 대한 지정 "의무"를 부과하고 있지 않다.

따라서 저수지의 농업진흥지역(농업보호구역) 지정 여부는 시·도지사의 재량에 따라 결정된다. 다만, 다음과 같은 요소가 지정 여부 판단에 영향을 미칠 수 있다:

| 고려 요소 | 지정 가능성 높음 | 지정 가능성 낮음 |
|-----------|------------------|------------------|
| 용수 공급 대상 | 농업진흥구역에 용수 공급 | 농업진흥구역 외 지역에 용수 공급 |
| 관개 면적 | 대규모 관개 면적 | 소규모 관개 면적 |
| 수질 보전 필요성 | 수질 보전 필요성 높음 | 수질 보전 필요성 낮음 |
| 주변 토지이용 | 농업적 이용 우세 | 비농업적 이용 우세 |

### 3) 화순군 저수지 미지정 사례의 해석

화순군에서 저수지가 농업진흥구역으로 지정되지 않은 사례가 많은 것은 다음과 같은 요인에 기인하는 것으로 해석된다.

#### (1) 구릉성 산지 지형 특성

화순군은 구릉성 산지 지형이 대부분을 차지하며, 농지가 산지 사이의 협소한 평탄지에 분산되어 있다. 이러한 지형 특성으로 인해:

- **소규모 저수지 다수 분포**: 대규모 관개 체계보다는 소규모 저수지가 개별 농지에 용수를 공급하는 형태가 우세
- **집단화된 농업진흥구역 부재**: 저수지가 용수를 공급하는 대상 농지가 농업진흥구역으로 지정되지 않은 경우, 해당 저수지도 농업보호구역으로 지정될 근거가 약화
- **직접유역 면적 제한**: 산지 지형으로 인해 저수지의 직접유역이 협소하여 농업보호구역으로 지정할 면적이 제한적

#### (2) 농업진흥구역과의 연계성 부족

농업보호구역은 농업진흥구역의 용수원 확보를 위해 지정하는 것이므로, 용수 공급 대상인 농업진흥구역이 존재해야 지정 근거가 확보된다. 화순군의 경우:

- 농업진흥지역 지정률이 8.05%로 나주시(26.64%)에 비해 현저히 낮음
- 보전 누락률이 55.88%로 높아 우량농지의 상당 부분이 농업진흥구역으로 지정되지 않음
- 저수지가 용수를 공급하는 농지가 농업진흥구역이 아닌 경우, 해당 저수지를 농업보호구역으로 지정할 근거가 약화

#### (3) 지정 목적에 따른 판단

저수지가 농업용수 공급 외에 다른 목적(생활용수, 공업용수, 홍수 조절 등)으로도 활용되는 경우, 농업보호구역 지정의 우선순위가 낮아질 수 있다. 화순군의 일부 저수지가 다목적으로 활용되고 있다면, 농업보호구역 지정에서 제외되었을 가능성이 있다.

### 4) 저수지 지정에 대한 정책적 판단

#### (1) 저수지 지정의 당위성

저수지의 농업보호구역 지정은 의무가 아니지만, 다음과 같은 측면에서 당위성이 있다.

**긍정적 측면:**

- **용수 공급 기능 보호**: 농업보호구역으로 지정되면 행위 제한을 통해 수질 오염을 방지하고 안정적인 용수 공급 기능을 유지할 수 있음
- **농업 기반시설 보전**: 저수지는 농업 생산의 핵심 기반시설로서, 제도적 보전을 통해 장기적인 농업 지속가능성을 확보할 수 있음
- **집단화된 관개 체계 유지**: 저수지와 주변 농지를 함께 농업진흥지역으로 지정함으로써 관개 체계의 일체성을 유지할 수 있음

**부정적 측면:**

- **토지이용 규제 강화**: 농업보호구역으로 지정되면 건축, 개발 행위 등에 제한이 가해져 토지 소유자의 재산권 행사가 제약됨
- **다목적 활용 제한**: 저수지가 농업 외 목적으로도 활용되는 경우, 농업보호구역 지정이 다른 활용을 제약할 수 있음
- **소규모 저수지의 관리 부담**: 소규모 저수지까지 모두 농업보호구역으로 지정하면 관리 행정 부담이 증가할 수 있음

#### (2) 정책적 권고

저수지의 농업보호구역 지정에 대해 다음과 같은 정책적 권고를 제시한다.

**① 농업진흥구역 용수 공급 저수지: 지정 권고**

농업진흥구역에 용수를 공급하는 저수지는 농업보호구역으로 지정하는 것이 바람직하다. 이는 농업보호구역의 본래 취지인 "농업진흥구역의 용수원 확보"에 부합하며, 안정적인 농업용수 공급 체계를 제도적으로 보장할 수 있다.

**② 비농업진흥구역 용수 공급 저수지: 선택적 지정**

농업진흥구역이 아닌 농지에 용수를 공급하는 저수지는 지정 여부를 선택적으로 결정한다. 다만, 해당 농지가 향후 농업진흥구역으로 신규 지정될 가능성이 높은 경우(C1, C2 지역)에는 저수지도 함께 농업보호구역으로 지정하는 것이 바람직하다.

**③ 규모 기준 도입 검토**

현행 규정에는 저수지 규모별 지정 기준이 없으나, 관리 효율성을 위해 규모 기준 도입을 검토할 필요가 있다. 예를 들어:

| 저수지 규모 | 지정 권고 |
|-------------|-----------|
| 유효저수량 10만㎥ 이상 | 농업보호구역 지정 권고 |
| 유효저수량 1만~10만㎥ | 용수 공급 대상에 따라 선택적 지정 |
| 유효저수량 1만㎥ 미만 | 지정 대상에서 제외 검토 |

이러한 규모 기준은 관리 효율성을 높이는 동시에, 대규모 농업용수 공급 시설에 대한 제도적 보전을 강화할 수 있다.

### 5) 본 연구에의 적용

#### (1) API 산출에의 시사점

본 연구의 API 산출 방식은 '농업 생산에 직접 활용되는 토지'를 평가하는 것을 목적으로 하므로, 저수지는 필연적으로 낮은 점수를 받게 된다. 이는 API 산출 방식의 한계라기보다는, 저수지가 농업 생산 토지가 아닌 농업 지원 시설이라는 본질적 특성을 반영한 것이다.

따라서 저수지가 부적정 지정(유형 B)으로 분류되는 것은 API 산출 방식의 구조적 특성에서 비롯된 것이며, 이를 제도적 문제로 해석하는 것은 적절하지 않다.

#### (2) 정합성 분석에의 시사점

정합성 분석 시 저수지의 처리 방안을 다음과 같이 제안한다.

**방안 1: 별도 유형 분류**

저수지를 유형 B(부적정 지정)와 별도로 분류하여 '농업 기반시설'로 구분한다. 이를 통해 실제 부적정 지정 면적을 보다 정확하게 파악할 수 있다.

| 유형 | 분류 | 정합성 평가 |
|------|------|-------------|
| A1, A2 | 적정 보전 | 우량농지 보전 성공 |
| B-1 | 부적정 지정 (실제) | 비농업 용도 전환 토지 |
| B-2 | 농업 기반시설 | 저수지, 농로 등 (적정 지정) |
| C1, C2 | 보전 누락 | 우량농지 보전 실패 |
| D | 적정 비지정 | 저위농지 적정 제외 |

**방안 2: 해제 검토 대상 제외**

유형 B 지역에 대한 해제 검토 시, 저수지는 해제 대상에서 제외한다. 저수지는 농업진흥구역의 용수원 확보를 위한 필수 시설이므로, API 점수와 관계없이 농업보호구역으로 유지하는 것이 타당하다.

## 나. 농업경영체 재배작물 정보를 활용한 모델 적정성 검토

### 1) 검토 배경 및 목적

본 연구에서 개발한 농지 잠재력 지수(API)는 4개 레이어(피복, 기반시설, 토양, 농업)의 공간 데이터와 계층적 엔트로피 가중치 분석을 결합하여 산출되었다. 그러나 이러한 평가 모델의 타당성을 검증하기 위해서는 실제 농업 생산 현황과의 비교가 필요하다.

농업경영체 등록정보에는 필지별 재배작물, 경작면적, 농업 경영 현황 등이 포함되어 있어, 이를 활용하면 API 모델의 적정성을 실증적으로 검토할 수 있다. 본 절에서는 농업경영체 데이터 활용의 타당성을 검토하고, 구체적인 분석 계획을 수립한다.

### 2) 농업경영체 등록정보 개요

#### (1) 데이터 구성

농업경영체 등록정보는 「농어업경영체 육성 및 지원에 관한 법률」에 따라 농업경영체가 등록한 정보로, 다음과 같은 항목이 포함된다.

**경영체 기본정보:**
- 경영체 유형 (개인, 법인)
- 대표자 정보
- 경영체 소재지

**경작지 정보:**
- 필지별 지번, 면적
- 소유/임차 여부
- 재배작물 (주작물, 부작물)
- 재배면적
- 재배 방식 (노지, 시설 등)

**농업 경영 정보:**
- 농업소득
- 농산물 판매 현황
- 농기계 보유 현황

#### (2) 데이터 특성 및 한계

**장점:**
- 필지 단위의 상세한 재배작물 정보 확보 가능
- 실제 영농 현황을 반영한 현실적 데이터
- 전국 농업경영체 대상 표준화된 정보

**한계:**
- 등록 농업경영체만 포함 (미등록 농가 제외)
- 자가 신고 기반으로 정확성에 한계
- 연도별 갱신 주기에 따른 시점 차이
- 개인정보 보호로 인한 접근성 제한

### 3) 모델 적정성 검토를 위한 타당성 평가

#### (1) 타당성 평가 결과: **타당함**

농업경영체 재배작물 정보를 활용한 API 모델 적정성 검토는 다음과 같은 측면에서 타당하다.

**① 실제 농업 생산 현황 반영**

API는 농지의 "잠재력"을 평가하는 지표이므로, 실제 농업 생산이 활발하게 이루어지는 농지에서 API가 높게 나타나야 모델의 타당성이 확보된다. 농업경영체 데이터는 실제 재배작물과 경작면적 정보를 제공하므로, API와 실제 영농 현황의 상관관계를 검증할 수 있다.

**② 독립적 검증 데이터**

API 산출에 사용된 4개 레이어(피복, 기반시설, 토양, 농업)와 농업경영체 데이터는 서로 다른 출처의 독립적인 데이터이다. 따라서 농업경영체 데이터를 활용한 검증은 순환 논증의 오류를 피할 수 있다.

| API 산출 데이터 | 검증 데이터 | 독립성 |
|-----------------|-------------|--------|
| 피복: 토지피복지도 | 농업경영체: 재배작물 | 독립 |
| 기반시설: 농업기반시설 DB | 농업경영체: 경작지 정보 | 독립 |
| 토양: 정밀토양도 | 농업경영체: 재배작물 | 독립 |
| 농업: 경지정리 현황 | 농업경영체: 재배면적 | 일부 연관 |

**③ 필지 단위 정밀 검증 가능**

본 연구는 래스터 픽셀 단위로 API를 산출했으나, 실제 정책 집행은 필지 단위로 이루어진다. 농업경영체 데이터는 필지별 정보를 제공하므로, 필지 단위의 API 평균값과 실제 영농 현황을 비교할 수 있다. 이를 통해 필지 단위 정책 적용의 타당성도 함께 검토할 수 있다.

**④ 작물별 차별화된 검증 가능**

농업경영체 데이터는 재배작물 정보를 제공하므로, 논농사(벼)와 밭농사(채소, 과수 등)를 구분하여 API의 타당성을 검증할 수 있다. 특히 본 연구에서 밭농사 지역의 보전 누락 문제를 지적했으므로, 실제 밭농사 지역의 API 분포를 분석하는 것이 중요하다.

#### (2) 예상 한계 및 보완 방안

**① 등록 농업경영체 편향**

농업경영체 등록은 의무가 아니므로, 등록하지 않은 농가의 필지는 분석에서 제외된다. 특히 소규모 영세 농가의 등록률이 낮을 수 있어, 분석 결과가 중대규모 농가에 편향될 수 있다.

*보완 방안*: 농업경영체 등록 현황(등록률)을 지역별로 파악하고, 등록률이 낮은 지역의 결과 해석 시 주의를 기울인다.

**② 시점 차이**

API 산출에 사용된 데이터와 농업경영체 데이터의 시점이 다를 수 있다. 시점 차이가 크면 토지이용 변화로 인해 비교 정확성이 저하된다.

*보완 방안*: 가급적 동일 연도의 데이터를 사용하고, 시점 차이가 있는 경우 이를 명시하고 결과 해석에 반영한다.

**③ 자가 신고의 정확성**

농업경영체 등록정보는 자가 신고 기반이므로, 실제 영농 현황과 차이가 있을 수 있다. 특히 재배면적, 재배작물 등에서 오류가 발생할 수 있다.

*보완 방안*: 이상치 탐지를 통해 명백한 오류 데이터를 제거하고, 표본 추출 현장 조사를 통해 정확성을 검증한다.

### 4) 분석 계획

#### (1) 분석 목표

농업경영체 재배작물 정보를 활용하여 다음 사항을 검증한다.

1. **API와 실제 영농 현황의 상관관계**: API가 높은 지역에서 실제 농업 생산이 활발하게 이루어지는지 확인
2. **등급별 재배작물 특성**: API 등급별로 재배작물의 종류, 재배면적, 영농 집약도 등에 차이가 있는지 분석
3. **영농 형태별 API 분포**: 논농사 지역과 밭농사 지역의 API 분포를 비교하여, 밭농사 지역의 보전 누락 문제를 실증
4. **정합성 유형별 영농 현황**: A, B, C, D 유형별로 실제 영농 현황에 차이가 있는지 분석

#### (2) 분석 데이터

**필요 데이터:**

| 데이터 | 출처 | 주요 항목 | 비고 |
|--------|------|-----------|------|
| 농업경영체 등록정보 | 농림축산식품부 | 필지별 지번, 재배작물, 재배면적 | 개인정보 제거 버전 |
| 농지 잠재력 지수(API) | 본 연구 산출 | 픽셀별 API 점수 | 래스터 데이터 |
| 연속지적도 | 국가공간정보포털 | 필지 경계 | 벡터 데이터 |
| 농업진흥지역 | 국가공간정보포털 | 농업진흥구역/보호구역 경계 | 벡터 데이터 |

**데이터 전처리:**

1. 농업경영체 데이터의 지번을 연속지적도와 연결하여 공간화
2. 연속지적도 필지별로 API 래스터의 평균값 산출 (Zonal Statistics)
3. 농업진흥지역 경계와 중첩하여 정합성 유형(A1, A2, B, C1, C2, D) 부여
4. 이상치 탐지 및 제거 (명백한 오류 데이터)

#### (3) 분석 방법

**분석 1: API와 영농 집약도의 상관관계**

*목적*: API가 높은 필지에서 영농 집약도가 높은지 검증

*방법*:
- 영농 집약도 지표 산출: 재배면적 / 필지면적
- API 등급별 영농 집약도 평균 비교 (ANOVA)
- API 점수와 영농 집약도의 상관계수 산출 (Pearson/Spearman)

*예상 결과*: API가 높을수록 영농 집약도가 높은 양의 상관관계 예상

*타당성 판단 기준*:
| 상관계수 | 해석 | 타당성 판단 |
|----------|------|-------------|
| 0.7 이상 | 강한 양의 상관 | 매우 타당 |
| 0.5~0.7 | 중간 양의 상관 | 타당 |
| 0.3~0.5 | 약한 양의 상관 | 일부 타당 |
| 0.3 미만 | 상관 없음 | 모델 재검토 필요 |

**분석 2: API 등급별 재배작물 특성**

*목적*: API 등급에 따라 재배작물의 종류와 구성이 다른지 분석

*방법*:
- API 등급별 재배작물 빈도 분석
- 주요 작물(벼, 채소, 과수, 특용작물 등) 비율 비교
- 카이제곱 검정을 통한 등급-작물 간 독립성 검정

*예상 결과*: API 1등급에서는 벼(논농사) 비율이 높고, 2~3등급에서는 밭작물 비율이 높을 것으로 예상

**분석 3: 논농사 vs 밭농사 지역의 API 분포**

*목적*: 밭농사 지역의 API가 논농사 지역과 비교하여 어떻게 분포하는지 분석

*방법*:
- 재배작물 기준으로 논농사 필지(벼)와 밭농사 필지(기타) 분류
- 영농 형태별 API 분포 비교 (히스토그램, 박스플롯)
- 평균 API, 표준편차, 등급 분포 비교 (t-test, Mann-Whitney U)

*예상 결과*:
- 논농사 지역: API 1~2등급 집중, 낮은 표준편차
- 밭농사 지역: API 1~3등급 분산, 높은 표준편차

*본 연구 가설 검증*: 밭농사 지역의 API가 논농사 지역과 유사하게 높게 나타난다면, 밭농사 지역의 보전 누락 문제가 실증됨

**분석 4: 정합성 유형별 영농 현황**

*목적*: 정합성 유형(A, B, C, D)별로 실제 영농 현황에 차이가 있는지 분석

*방법*:
- 정합성 유형별 영농 집약도, 재배작물 구성 비교
- 특히 유형 B(부적정 지정)와 유형 C(보전 누락)의 영농 현황 중점 분석
- 유형별 영농 현황의 통계적 차이 검정

*예상 결과*:
- 유형 A1, A2: 높은 영농 집약도, 논농사 우세 → API 모델 타당성 확인
- 유형 B: 낮은 영농 집약도 또는 비농업 이용 → 부적정 지정 확인
- 유형 C1, C2: 높은 영농 집약도, 밭농사 비율 높음 → 보전 누락 문제 실증
- 유형 D: 낮은 영농 집약도 또는 영농 미등록 → 적정 비지정 확인

*본 연구 가설 검증*:
- 유형 C(보전 누락)에서 실제 영농이 활발하게 이루어지고 있다면, 해당 지역의 신규 지정 필요성이 실증됨
- 유형 B(부적정 지정)에서 영농이 저조하다면, 해제 검토의 타당성이 확인됨

**분석 5: 영농 지속성 예측 모델**

*목적*: API가 영농 지속성(농업경영체 등록 지속, 재배면적 유지 등)을 예측하는지 검증

*방법* (시계열 데이터 확보 시):
- 복수 연도의 농업경영체 데이터 확보
- API 등급별 영농 지속률 (2년 이상 영농 유지 비율) 비교
- API를 독립변수, 영농 지속 여부를 종속변수로 하는 로지스틱 회귀분석

*예상 결과*: API가 높을수록 영농 지속률이 높은 양의 관계 예상

#### (4) 결과 활용 방안

분석 결과는 다음과 같이 활용한다.

**① API 모델 타당성 확인**

API와 실제 영농 현황의 상관관계가 높게 나타나면, 본 연구의 API 산출 방식이 농지의 실질적 가치를 적절히 반영하고 있음이 실증된다. 이를 통해 API 기반의 농업진흥지역 설정기준안의 정당성이 강화된다.

**② 밭농사 보전 누락 실증**

밭농사 지역의 API가 높게 나타나고 실제 영농도 활발한 것이 확인되면, 현행 논농사 위주 집단화 기준의 한계가 실증된다. 이를 근거로 밭농사 지역에 대한 별도 지정 기준 마련의 정당성을 확보할 수 있다.

**③ 정합성 분석 결과 보완**

정합성 유형별 영농 현황 분석을 통해, 유형 B(부적정 지정) 중 실제 부적정 지정 비율과 유형 C(보전 누락) 중 실제 보전 필요 비율을 보다 정확히 파악할 수 있다. 이를 통해 재조정 대상 면적을 보다 정밀하게 산출할 수 있다.

**④ 향후 연구 방향 설정**

분석 결과 API 모델의 한계점이 발견되면, 이를 보완하기 위한 향후 연구 방향을 설정할 수 있다. 예를 들어, 특정 작물에 대해 API가 과소 또는 과대 평가되는 경향이 있다면, 레이어 구성이나 가중치 산출 방법을 개선할 필요가 있다.

## 다. 심층 검토 종합

### 1) 저수지 지정 검토 결론

**① 법적 기준**

- 저수지의 농업보호구역 지정은 **의무가 아닌 재량**
- 규모별 지정 기준은 **존재하지 않음**
- 지정 판단 요소: 용수 공급 대상(농업진흥구역 여부), 관개 면적, 수질 보전 필요성 등

**② 화순군 사례 해석**
