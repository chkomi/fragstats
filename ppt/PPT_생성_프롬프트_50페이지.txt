전체 연구 개요
========================================

【연구 제목】
계층적 엔트로피 분석을 활용한 농지 잠재력 평가 및 농업진흥지역 정합성 분석
- 부제: 나주시와 화순군을 사례로

【연구 목적】
1. 객관적이고 과학적인 '농지 잠재력 지수(Agricultural Potential Index, API)' 평가 모델 개발
2. 계층적 엔트로피 분석을 통한 평가 레이어별 가중치의 객관적 산정
3. FRAGSTATS 경관지수를 활용한 공간 구조적 특성 정량화
4. 기존 농업진흥지역 지정의 적정성 평가 및 정책적 시사점 도출

【연구 대상 지역】
- 화순군: 상대적으로 기복이 있는 지형, 논 적성등급 중심
- 나주시: 평탄한 지형, 기반시설·피복현황 중심

【핵심 방법론】
1. FRAGSTATS를 활용한 경관지수 분석 (30개 지표, 4개 그룹)
2. 계층적 엔트로피 가중치 분석 (3단계 계층 구조)
3. GIS 래스터 중첩 분석을 통한 농지 잠재력 지수 산출
4. 농업진흥지역과의 정합성 분석 (4가지 유형 분류)

【주요 결과】
- 화순군: 논 적성등급 41.53% (1위), 피복현황 23.36%, 토양 18.01%, 기반시설 17.10%
- 나주시: 피복현황 38.55% (1위), 기반시설 38.16%, 논 적성 15.98%, 토양 7.31%
- 지역별 농지 잠재력 지수 4단계 등급 분류도 제시
- 농업진흥지역 부적정 지정 및 누락 지역 식별

【슬라이드 20】 계층적 엔트로피 분석 절차
단계별 상세 과정:

【Step 1】 그룹 내 지표 가중치 산정
1. 각 그룹에서 지표별 엔트로피 계산
   E_ij = -Σ(p_ik × ln(p_ik))
2. 효용도 계산: D_ij = 1 - E_ij
3. 가중치 산정: W_ij = D_ij / ΣD_ij

【Step 2】 그룹 대표 점수 및 변별력 계산
1. 그룹 대표 점수: S_group = Σ(W_ij × V_ij)
2. 변별력: D_layer = Σ|S_group_cls1 - S_group_cls9|

【Step 3】 레이어별 최종 가중치
W_layer = D_layer / ΣD_layer

【슬라이드 21】 농지 잠재력 지수(API) 산출 방법
GIS 래스터 중첩 분석:

API(x,y) = Σ(W_layer × V_layer(x,y))

여기서:
- W_layer: 레이어별 가중치 (Step 3 결과)
- V_layer(x,y): (x,y) 위치에서 레이어 값
  · cls_1이면 1
  · cls_9이면 0

결과: 0.0 ~ 1.0 범위의 연속 값

4단계 등급 분류:
- 1등급 (최우량): 0.75 ≤ API ≤ 1.00
- 2등급 (우량): 0.50 ≤ API < 0.75
- 3등급 (보통): 0.25 ≤ API < 0.50
- 4등급 (저급): 0.00 ≤ API < 0.25

- 패치 내 각 픽셀에서 중심까지의 평균 거리
- 높은 값 = 공간적으로 넓게 확장된 패치
- 낮은 값 = 공간적으로 응축된 패치

농업적 의미:
- 높은 회전반경 → 대규모 영농 작업 가능, 공간 효율성 높음
- 낮은 회전반경 → 제한적 작업 공간

회전반경 69.65%의 의미:
→ 농지의 공간적 확장성이 연결성 평가의 핵심
