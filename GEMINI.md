# GEMINI.md - Project Context and Guidelines

## Directory Overview

This directory contains a research project focused on **evaluating agricultural land potential and informing zoning policy**. The central goal is to develop a "Farmland Potential Index" by analyzing the spatial structure of various land characteristics.

The methodology involves:
1.  Quantifying landscape patterns using **FRAGSTATS** metrics.
2.  Applying a custom **Hierarchical Entropy Weighting model** to calculate the relative importance of different landscape characteristics (referred to as "layers").
3.  Using the calculated index to assess the validity of existing "Agricultural Promotion Areas" and provide data-driven policy recommendations.

The project is a hybrid of data analysis (using Python) and academic writing, with the final output being a research paper/thesis.

*   `results/`: The directory for all **analysis outputs**. Scripts save their results here, typically in timestamped subdirectories.

## Usage: Analysis Workflow

The primary workflow for this project involves running the data analysis scripts and then using the results to inform the writing process.

1.  **Data Preparation**: Ensure that the raw FRAGSTATS output files (e.g., `infra_class.txt`, `pibok_class.txt`) are placed in the `data/01_raw_fragstats/` directory.

2.  **Execute Analysis**: To run the complete hierarchical entropy analysis, execute the main script from the project root:
    ```bash
    python scripts/hierarchical_entropy_analysis.py
    ```

3.  **Retrieve Results**: The script will automatically create a new, timestamped directory within `results/06_hierarchical_entropy_analysis/`. This directory will contain the key outputs as CSV files:
    *   `01_group_indicator_weights.csv`: Weights of individual metrics within each of the 4 defined groups.
    *   `02_group_representative_scores.csv`: The composite score for each group.
    *   `03_final_layer_weights.csv`: The final, most important output—the calculated weights for each top-level layer (e.g., `pibok`, `infra`, `toyang3`).

4.  **Incorporate and Revise**: Use the numerical results from the CSV files to write the findings, create tables, and revise the manuscript in the `paper/` and `reports/` directories. Use the `첨삭필요.txt` file as a guide for manuscript revisions.
