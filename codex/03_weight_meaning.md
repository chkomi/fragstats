# 가중치가 의미하는 것
- 지표 가중치(W_indicator): 엔트로피 기반 정보량 비율. 값이 클수록 해당 지표가 cls_1과 cls_9를 더 잘 구분하며, 다른 지표로 대체하기 어렵다는 뜻. 값의 합은 그룹별로 1.
- 그룹 대표 점수: 정규화된 지표값에 지표 가중치를 곱해 합산한 값으로, 각 그룹(면적·밀도 등)의 종합 성과를 나타냄.
- 변별력(discriminability): 동일 레이어에서 cls_1 점수와 cls_9 점수의 절대 차이. 값이 클수록 해당 레이어가 농업진흥지역과 비농지의 공간 구조 차이를 크게 드러낸다는 뜻.
- 레이어 가중치(W_layer): 변별력의 합을 1로 표준화한 값. W_layer가 높을수록 해당 레이어(예: nongeup, toyang)가 API 계산에서 더 큰 영향력을 가짐.
- API 계산에서의 역할: 최종 점수 Score(x,y) = sum(W_layer * V_layer). 여기서 V_layer는 픽셀이 cls_1이면 1, cls_9면 0. 따라서 W_layer는 "어떤 레이어의 적합성이 최종 의사결정에 얼마나 기여하는가"를 수치화한다.
- 모든 가중치는 데이터 기반(엔트로피+변별력)으로 산정되어, 주관적 가정이 아니라 실제 공간 패턴이 지닌 정보량을 반영한다.
