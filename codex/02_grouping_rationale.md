# 4개 그룹으로 묶은 이유
- FRAGSTATS 이론 분류(면적·밀도, 형태·경계, 코어, 응집·연결성)에 맞춰 동일 성격 지표를 묶어 해석력을 높이고, 동일 차원 내 중복을 제어.
- 계층적 엔트로피 가중치 알고리즘에서 그룹 단위로 1차 엔트로피 계산 → 그룹 대표 점수 → 변별력 산정 → 레이어 가중치 산정 흐름을 유지하려면 선행 그룹핑이 필요.
- 지표 간 상관성이 높은 항목을 같은 그룹에 넣어 그룹 내부에서만 정규화·가중치를 분배함으로써 과도한 중복 가중(멀티콜리니어티) 위험을 줄임.
- 정책 해석 측면에서 네 그룹이 각기 다른 질문을 던짐:
  - 면적·밀도: 얼마나 넓고/잘게 쪼개졌는가?
  - 형태·경계: 경계가 얼마나 복잡해 관리비용이 높아지는가?
  - 코어: 경계 영향이 배제된 실질 농업 공간이 얼마나 남는가?
  - 응집·연결성: 패치가 서로 얼마나 이어져 접근성과 기능적 연속성을 보장하는가?
- 동일 그룹 내 30개 지표는 상호보완 관계로 구성되어, 그룹별 점수가 특정 방향으로 치우치지 않도록 균형 있게 설계됨.
